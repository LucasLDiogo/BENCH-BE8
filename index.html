⚙ Como integrar esta página ao Power BI

A ANP disponibiliza o levantamento semanal de preços em CSV na URL:

https://www.gov.br/anp/pt-br/centrais-de-conteudo/dados-abertos/serie-historica-de-precos-de-combustiveis

Pipeline recomendado (Power Query M):

  1. Web.Contents na URL do CSV mais recente (publicado toda 6ª-feira)
  2. Csv.Document com encoding 1252 (Windows-1252)
  3. Promote first row as headers, transformar `Data da Coleta` para Date
  4. Renomear `Preço de Revenda` → `preco_venda`
  5. Carregar como `fato_combustivel_anp` no modelo estrela
  6. Configurar refresh diário no Power BI Service

Após carregado, esta página exibirá automaticamente os valores reais consumindo o mesmo dataset via API REST do Power BI (`api.powerbi.com/v1.0/myorg/datasets/{id}/executeQueries`).
